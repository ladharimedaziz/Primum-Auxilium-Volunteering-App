# Primum Auxilium Volunteering App

ONLY FOR MEIS Students

The official app of **Primum Auxilium**, the student volunteering team. It tracks volunteer hours toward the 40-hour requirement, events and sign-ups, certificates, reports, and team handbooks.

## Windows 11 app

1. Open **[Releases](../../releases/latest)** and download `Primum-Auxilium-Windows11.zip`.
2. Unzip it anywhere, for example `Documents`.
3. Open the folder and run **Primum Auxilium.exe**.

Windows may show "Windows protected your PC" the first time. Click **More info**, then **Run anyway**.

### Updates

Open **Settings › App updates › Check for updates**. Updates install in place and keep all data. Only updates signed by the team are accepted.
